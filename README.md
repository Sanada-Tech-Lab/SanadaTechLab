# Sanada Tech Lab

会社サイト <https://sanadatechlab.com/> のソース。
静的 HTML の3ページ構成で、外部ファイルへの依存は Google Fonts だけ。
ビルドは不要で、ファイルをブラウザで開けばそのまま表示できる。

## 構成

```
html/
├─ index.html    トップ。事業内容・制作物・ご依頼の流れ・事業概要
├─ about.html    経歴。扱ってきた開発言語とシステム
└─ contact.html  問い合わせ
```

配信するのは `html/` の中だけ。この README のような開発用の文書を
サイト上に出さないよう、リポジトリ直下ではなく1階層下げてある。

CSS は各 HTML に埋め込んでいる。共有のスタイルシートは持たない。

## 公開のしかた

Cloudflare Pages に置いている。`main` へ push すると自動で再デプロイされ、
1分ほどで反映される。

Pages 側の設定は次のとおり。

| 項目 | 値 |
|---|---|
| 本番ブランチ | `main` |
| フレームワークのプリセット | なし |
| ビルドコマンド | （空欄） |
| ビルド出力ディレクトリ | `html` |
| 独自ドメイン | `sanadatechlab.com` |

**出力ディレクトリは `html`。** `/` にすると、サイトの中身ではなく
この README が公開されてしまう。

反映されないときは Pages の［デプロイ］タブでビルドログを見る。
ブラウザのキャッシュで古いままに見えることもあるので、Ctrl+F5 で確認する。

なお Pages は `/about.html` を `/about` へ 308 で正規化する。
拡張子付きのリンクのままでも表示されるが、リダイレクトが1回挟まる。

## 問い合わせの受け方

`mailto:info@sanadatechlab.com` のリンクだけを置いている。
静的サイトなので、入力フォームを置いても送信内容を受け取る先がない。

フォームが必要になったら、Cloudflare Workers と送信 API を組み合わせて用意し、
スパム対策に Cloudflare Turnstile を併用する。

## デザインの決めごと

- **色** 赤備えの臙脂 `#9B2335` を唯一のアクセント。地は寒色寄りの紙色
- **書体** 見出しに Shippori Mincho B1（明朝）、本文に Zen Kaku Gothic New、
  技術表記に JetBrains Mono
- **マーク** 六文銭。円形方孔（丸に四角い穴）の六枚を 3×2 で並べる
- **番号** ご依頼の流れにだけ振っている。実際に順序があるため

ライトとダークの両方に対応している。

## 手を入れるときに

- 配色は各ファイル冒頭の `:root` にある CSS 変数で持たせている。
  ダーク側は `@media (prefers-color-scheme:dark)` の中で同じ変数を上書きする
- 3ページで CSS を共有していない。1枚ものとして完結させるための割り切りなので、
  見た目を変えるときは3ファイルとも直す
- ブレークポイントは 640px と 720px の2つ
