## 公開のしかた

**Cloudflare Pages に変更した。** 当初は GitHub Pages を想定していたが、
ドメインと DNS を Cloudflare にまとめる構成にしたため、サイトも同じところに置く。

手順は `../05_ドメインとメール/ドメイン・メール開設手順書.xlsx` の
「ホームページ公開」シートにまとめてある。おおまかには次のとおり。

1. GitHub に新しい**公開**リポジトリを作る（例：`SanadaTechLab`）
2. `index.html` を置いて push
3. Cloudflare の［Workers & Pages］で、そのリポジトリに接続する
   （静的 HTML なのでビルドコマンドは空欄でよい）
4. ［カスタムドメイン］に `sanadatechlab.com` を足す

GitHub Pages でも同じことはできる。慣れているほうでよい。

**公開先は Cloudflare Pages に決めた**（DNS を Cloudflare に集約するため）。

## デザインの決めごと

- **色** 赤備えの臙脂 `#9B2335` を唯一のアクセント。地は寒色寄りの紙色
- **書体** 見出しに Shippori Mincho B1（明朝）、本文に Zen Kaku Gothic New、
  技術表記に JetBrains Mono
- **マーク** 六文銭。円形方孔（丸に四角い穴）の六枚を 3×2 で並べる
- **番号** 受託の流れにだけ振っている。実際に順序があるため

ライトとダークの両方に対応済み。
